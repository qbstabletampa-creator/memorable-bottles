How to install

  1. Gmail: Settings (gear) → See all settings → Signature → Create new → paste → Save changes at the bottom.
  2. iPhone Mail: Mail signatures are text only. Use the Gmail or Yahoo app instead, both keep the design.
  3. Yahoo Mail: Settings → More settings → Writing email → Signature → toggle on → paste.
